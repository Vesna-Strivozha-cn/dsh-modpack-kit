# dsh-modpack-kit（DSH 也要整合包）

把多个 DSH 插件打成一个 `.dshpack`，一次装好。换台机器、少个插件、版本对不上时，不用再一个个搜、一个个装。

- **两种包**：完整版自带插件本体（对方没装本插件，照包内 `README.txt` 手工也能装）；轻量版只记名字与版本，安装时按记录取包，体积小。
- **逐插件模式**：每个插件单独选「基础配置」（上游原版 + 默认配置）或「本地改动」（你本机的代码、配置、数据快照）。
- **安全**：打包前**强制**检测敏感信息与风险代码，命中只留掩码、原文不落盘；安装前再校验 sha256 完整性、兼容性与许可证。它不替代杀毒软件，也不证明某个插件安全。
- **装完能收尾**：按条目回填包内配置（只动目标那条），可选「装好先不启用」——只装文件，不登记 bundle，重启也不加载。
- **跟插件市场同源**：分类是市场那 23 个分区，首屏只列你已装的，搜索与分页走市场目录；同名插件行末有「（切换市场版）」。
- **三处入口**：设置页、侧边栏、插件页内各一个独立开关，改完立即生效；至少留一处，最后一个不能再关。

## 安装

在已装 DSH 的机器上：

```bash
dsh plugin --profile desktop add dsh-modpack-kit
```

或本地开发目录（本项目就在 `D:\桌面\蛆\整合包`）：

```bash
dsh plugin --profile desktop add "file:D:/桌面/蛆/整合包"
```

装完重启 DSH，左侧栏出现「整合包」。

## 与插件市场

- 目录同源：直接读插件市场自己的目录包 `dsh-plugin-catalog`（先走 CDN 的 `index.json`，取不到退回 npm tarball），条目与分区跟市场一致；插件市场没装也能用，只是少了它的界面。
- 安装同路：都走 `dsh plugin --profile <p> add`，两边装的插件互相可见，不需要各记一份状态。
- 已装插件会用目录补齐描述与分区，并标出「市场版 vX」。

## 分类、搜索与分页

- 分类就是插件市场的 23 个分区（全部 / AGI 架构探索 / UI 增强 / 用量与计费 / 主题与外观 / 模型与账号接入 / 身份与通信 / 会话与消息 / 记忆 / 工具与能力 / WSL 与 Windows 互操作 / 浏览器与网页 / 视觉与多模态 / 语音与音频 / 文档与渲染 / 技能包 / 工作流与自动化 / Git 与代码评审 / 通知与集成 / 开发与运行时 / 安全与权限 / 远程与移动端 / 插件市场与管理 / 娱乐），名字和条目数都从市场目录里读。
- **首屏只列本机已装的插件**，不联网、不卡顿。输入关键词或点分类才去目录里搜，结果是服务端分页，一页 20 条（设置里可改），底部「加载更多」再取下一页。
- 排序照抄市场的规则：**已装优先**，再按相关度（整字段命中 > 包含 > 其它词；包名权重最高，其次所有者、仓库，描述与分类最低），同分保持目录原序。本机独有、目录里没有的插件也能被搜到。
- 本机已装的插件如果目录里有同名条目，行末会有小字「（切换市场版）」：点一下改用上游原版代码 + 默认配置打包，装出来和你从插件市场装一样；再点一次「（切回本机版）」回到本机快照。同名不代表一定是同一个插件，所以它只是**选项**，默认仍打本机那份。

## 显示位置（三处独立开关）

设置页底部三个开关，各自独立，改了立刻生效，不用重启：

| 开关 | 显示在哪 |
|---|---|
| 在设置里显示 | 设置页内一栏「整合包」（含插件的插件设置 tab） |
| 在侧边栏显示 | 左侧栏「整合包」入口 |
| 在插件页内显示 | 插件的插件页里，跟插件市场同一位置，单开一栏「整合包」 |

三个全关会被拒绝（`POST /settings` 返回 400）——否则就再没有入口能把它关回来了；只关侧边栏是允许的，那时从设置页进。

## 逐插件：基础配置 / 本地改动

打包时每个插件可以单独选：

- **基础配置**：上游原版代码 + 插件默认配置，不带你的改动（会按版本从 registry 重下并校验 sha512）。
- **本地改动**：你本机现在的代码、配置条目、数据快照一起打进去。

顶部的「默认打包本机修改」只是勾选时的默认值，勾上后仍可逐个改；结果里会标明每个插件用了哪种。

## 两种包

| 版本 | 内容 | 适用 |
| --- | --- | --- |
| 完整版 `full` | 清单 + 插件文件 + 配置 + 检测报告 | 对方没装本插件也能按 README 手工装；离线可用 |
| 轻量版 `lite` | 清单 + 配置 + 检测报告 | 体积小，安装时联网按版本取包 |

两者都带 `integrity.json`（sha256）、`security/report.txt` 与不依赖本插件的手工安装说明。

## 开发

```bash
EXE="/d/大肥鱼/DeepSeek Harness.exe"
# 单测 / 宿主路由 / 联网烟测
ELECTRON_RUN_AS_NODE=1 "$EXE" test/run.mjs
ELECTRON_RUN_AS_NODE=1 "$EXE" test/host-smoke.mjs
ELECTRON_RUN_AS_NODE=1 "$EXE" test/live.mjs
# 改完源码：同步到 profile 副本（file: 依赖是硬链接拷贝，cp 会 EBUSY）并校验
ELECTRON_RUN_AS_NODE=1 "$EXE" dev/tools/sync.cjs
ELECTRON_RUN_AS_NODE=1 "$EXE" dev/tools/verify.cjs
```

本机没有独立的 node：用 `ELECTRON_RUN_AS_NODE=1` 借 DSH 自带的 Node 跑脚本。

`dev/tools/sandbox-e2e.mjs` 是端到端演练：从本机挑一个真插件打成包 → 读回校验 → 装进临时 profile `modpack-sandbox-tmp`（先不启用）→ 断言依赖写入、`bundles` 仍为空、desktop profile 一字未动 → 最后删掉临时 profile 与临时目录。它不碰你的 desktop profile。

`dev/dsh-refs/` 是官方插件文档的本地参考副本，不参与发布（`files` 里没有 `dev`）。`dev/tools/check-categories.mjs` 只读核对分类分布与「哪些已装插件在市场里有同名条目」。

## 安全检测

- **打包前是强制的，关不掉**：设置与包选项里的开关照常显示，但点它只会弹一行红字「你想干什么」，五秒后自己消失；就算直接调 API 写 `scanBeforePack: false`，服务端也会拉回 `true`，`buildPack` 里根本没有不扫的分支。
- 安装前各一次，静态读文本，不执行任何代码（安装前扫描仍可在设置里关，但默认开）。
- 规则覆盖：私钥、云厂商/代码托管 token、模型 key、Cookie 与会话字段、邮箱/手机号/身份证、内网 IP、本机路径；`curl|sh`、`powershell -enc`、`eval`、可疑长 base64、关闭证书校验、安装脚本等。
- 命中原文不落盘：报告只留规则名、文件、行号与掩码；同一文件同一行同一规则只记一条（一个文件里反复出现的 `exec(` 不会刷成几十行）。
- 高风险默认拒绝（只有显式 `force` 才继续，且写进清单 `security.approvedRisk`）；完整版与轻量版一视同仁。
- 轻量包在「下载完、真正安装前」还会对本机刚解出来的代码补扫一遍，高危同样阻断（不是只信清单里那份报告）。
- 包内 `integrity.json` 缺失或清单对不上，一律阻断（要显式 `force`）。
- 解压有体积、压缩比与条目数上限，解压时还按声明长度卡输出（防 zip bomb），拒绝路径逃逸、符号链接、加密条目。
- 只允许 https 与白名单域名下载，逐跳校验重定向。

## 安装与「先不启用」

- 安装走官方 `dsh plugin add`（和插件市场同一条链路）：优先直接起宿主 exe + 内置 `cli.js`，参数不经 `cmd`，所以中文用户名、带空格路径都不会被引号吃掉；找不到才退回 `.cmd`。
- 勾「装好先不启用」时，插件文件与依赖照装，但装完会把 `dsh.profile.bundles` 精确撤回原样 —— 重启也不会加载，想启用再手动加回来。
- 解包前会先清掉 `vendor/<包>/` 里的旧目录，避免上一版残留文件混进新版本。

**它不是杀毒软件**：静态检测会漏也会误报，装第三方插件前仍应自己看来源。

## 配置同步

包内 `configs/<name>.json` 保存打包时 profile 补丁层里的条目。安装时按条目 `upsert` 回 `cordis.patch.yml`：只动目标插件那一条，其它字节保留；已有本地配置且开启「保留本地修改」时跳过。

## 二次开发

- `lib/` 下每个模块都可单独 import：`zip`/`tar` 是通用读写器，`scan` 可接 `extraRules`，`yamlish` 只服务 `cordis.patch.yml`。
- 清单里的 `extensions` 字段打包时原样写入、安装时原样保留，可放自定义数据。
- 设置项 `extraScanRules` 会把额外规则并进扫描器。
- 页面只消费 `/dsh-modpack-kit/api/*`，换 UI 不必改后端。
